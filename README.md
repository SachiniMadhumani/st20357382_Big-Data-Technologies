# st20357382_Big-Data-Technologies

Download the below datasets and add these datasets into this path "data/raw"
1. Chicago Crime Dataset - https://www.kaggle.com/datasets/utkarshx27/crimes-2001-to-present
2. Socio-economic Dataset - https://www.kaggle.com/datasets/umermjd11/socioeconomic-indicators-in-chicago-2008-2012?utm_source=chatgpt.com
3. Weather Dataset - https://www.ncei.noaa.gov/data/global-historical-climatology-network-daily/access/USW00014819.csv


Technologies used:
Python
Apache Spark
PySpark
Spark SQL
Spark MLlib
Parquet
Jupyter Notebook
Matplotlib
Pandas


Processed data is in "data/processed" location
